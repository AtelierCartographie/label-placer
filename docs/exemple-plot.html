Une carte faite en code, avec Observable Plot

Les 50 pays d'Europe en cercles proportionnels à leur population, tracés par Observable Plot. Plot projette et dessine ; label-placer place les noms. L'adaptateur placeText() se branche sur l'option render d'un Plot.text : il lit les positions projetées et les rayons des cercles, mesure les noms, les place et dessine les filets. Plot n'est pas une dépendance du paquet.

Une carte faite en code se relit et se reprend. Le moteur est déterministe, et la case « Montrer ce qu'il reste à revoir » marque en rouge les noms en chevauchement, d'une croix les noms masqués faute de place hors des obstacles (blocked : voir les obstacles, le cadre ou la taille), d'un cercle ceux dont d'autres noms ont pris la place (voir les priorités, l'espacement, la taille du texte). Survolez une marque pour lire le nom.

Le code

Le canal r passe par l'échelle r de Plot, comme pour Plot.dot : le moteur connaît le rayon de chaque cercle. Sans canal priority, les plus gros cercles passent d'abord. land est projeté avec la projection du graphique : les noms préfèrent la mer, sans s'interdire la terre. Les autres options sont celles de placeLabels (spacing, leader, positions, previous...), en pixels. onPlace reçoit le résultat : gardez-le comme previous du rendu suivant, pour que les noms bougent le moins possible quand les données changent.
